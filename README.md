# SoundSnap

Real-time multiplayer music quiz. Create a room, invite friends with a room code, configure game settings (solo/teams, points to win, genres, modifiers), then play: spin the wheel to pick the first player, hear a short song preview, answer questions, and earn points.

## Stack

- **Next.js 15** (App Router, TypeScript)
- **Convex** (database + real-time)
- **Clerk** (auth)
- **TailwindCSS**, **Framer Motion**, **Zustand**

## Setup

1. **Install and Convex**
   ```bash
   npm install
   npx convex dev
   ```
   Sign in to Convex when prompted; this creates a project and sets `NEXT_PUBLIC_CONVEX_URL` in `.env.local`.

2. **Clerk (keyless mode)**
   - No signup or API keys needed to start. Run the app; Clerk uses temporary local keys.
   - Sign in or sign up in the app to create your first test user. If you see "Configure your application" in the corner, you can click it later to claim the app and get the Dashboard.
   - When you want production auth: add `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` and `CLERK_SECRET_KEY` to `.env.local` from [dashboard.clerk.com](https://dashboard.clerk.com).

3. **Wire Convex to Clerk (fix "Not authenticated" for create/join game)**
   - **Clerk:** In [Clerk Dashboard](https://dashboard.clerk.com) → JWT Templates, create a template named **`convex`** (this is the `applicationID` Convex expects). Use the default claims or add `aud: "convex"` if required.
   - **Convex:** In [Convex Dashboard](https://dashboard.convex.dev) → your project → Settings → Environment Variables, add `CLERK_JWT_ISSUER_DOMAIN` = your Clerk Frontend API URL (e.g. `https://YOUR_INSTANCE.clerk.accounts.dev`, from Clerk Dashboard → API Keys).
   - Add the same `CLERK_JWT_ISSUER_DOMAIN` to `.env.local` so `npx convex dev` can use it. Then restart `npx convex dev`.

4. **Seed songs**
   In the Convex dashboard, run the internal mutation `seed:seedSongs` once (or add a script that calls it) so the game has songs to pick from.

5. **Run**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000). Sign in, create a game, share the room code, and start playing.

## Project layout

- `src/app` – Home, lobby (`/lobby/[roomCode]`), game (`/game/[roomCode]`)
- `src/components` – Lobby (settings, player list), game (spin wheel, round, question card), shared (scoreboard)
- `src/lib/audio` – Abstract audio service and `usePreviewPlayer` (ready for Spotify or other providers)
- `convex` – Schema, auth helpers, game engine, rooms, rounds, answers, songs, seed

## Convex

- Use **`npx convex dev`** for local development (not `deploy`).
- After schema or function changes, types in `convex/_generated` are regenerated by `convex dev`.
